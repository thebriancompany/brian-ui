# 코드 글꼴

`JetBrainsMono-Regular.ttf`는 수정하지 않은 JetBrains Mono Regular입니다.
문서 앱의 코드 블록·파일명·인라인 코드에서 `BrianCode`라는 등록 이름으로 사용합니다.
글꼴은 앱 자산에 포함하므로 방문 시 별도 글꼴 서버에 요청하지 않습니다.

- 원본: https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/ttf
- 라이선스: 함께 보관한 `OFL.txt` (SIL Open Font License 1.1)

디자인 시스템의 코드용 타이포그래피가 생기면 글꼴 지정과 코드 스타일을 함께
검토하여 이관합니다. 일반 본문 글꼴이나 Brian UI 패키지의 기본값은 바꾸지 않습니다.
