# Brian Design System

Brian UI는 Flutter 기본 위젯 계층으로 만드는 독립 디자인 시스템입니다.
`brian_ui` 패키지로 디자인 토큰, 테마와 컴포넌트를 제공합니다.

[문서 사이트](https://thebriancompany.github.io/brian-ui/)

## 컴포넌트

- [Divider 사용 가이드](https://github.com/thebriancompany/brian-ui/blob/develop/doc/components/divider/divider.md) — 섹션·목록·가로 배치의 시각적 경계
- [Scroll Fog 사용 가이드](https://github.com/thebriancompany/brian-ui/blob/develop/doc/components/scroll_fog/scroll_fog.md) — 스크롤 경계 그라디언트

- [Badge 사용 가이드](https://github.com/thebriancompany/brian-ui/blob/develop/doc/components/badge/badge.md) — 상태·분류·부가 정보 라벨

## 디렉터리

- [lib](https://github.com/thebriancompany/brian-ui/tree/develop/lib) — 디자인 토큰, 테마와 Flutter 컴포넌트
- [doc](https://github.com/thebriancompany/brian-ui/tree/develop/doc) — 디자인 기준, 사용법과 기여 가이드
- [website](https://github.com/thebriancompany/brian-ui/tree/develop/website) — 문서 사이트와 컴포넌트 예제
- [test](https://github.com/thebriancompany/brian-ui/tree/develop/test) — 토큰과 컴포넌트 테스트
- [tool](https://github.com/thebriancompany/brian-ui/tree/develop/tool) — 문서 동기화와 웹사이트 빌드 도구
